# MorthenTooltips

A small, lightweight tooltip addon for *Retail WoW*. It adds the information the
default tooltip leaves out and gets out of the way when the game says it has to.

Configure it in *Options → AddOns → MorthenTooltips*. Available in **English** and **German**.

## Features

**General**
- **Anchor to cursor** – left, center or right of the cursor
- **Tooltip scaling** – 5% to 300%
- **Hide health bar** on unit tooltips
- **Class coloring** for the name, guild and class line of a hovered player
- **Hide in combat**, picked per type: player, unit, spell, mount, aura, item, toy,
  currency, quest, macro, achievement

**IDs** – add the numeric ID to unit, spell, mount, aura, item, toy, currency,
quest (tooltip *and* quest log), macro and achievement tooltips, plus the icon's
file ID.

**Player info** – extra lines on a hovered player, each toggled on its own:
- **Item level** – inspected from the server, cached, throttled
- **M+ score** – current season, colored by rating
- **Target** – class colored, NPCs marked
- **Mount** – name of the mount they are riding
- **Guild rank** – appended to the guild line
- **Language** – spoken on their realm (US, EU, KR and TW realms)

**Group finder** – the leader's realm language on a group's tooltip, and a country
flag next to every applicant.

Everything except the general options is off by default.
